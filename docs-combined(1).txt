## 1. 项目概述

**JoyData** 是一个面向游戏公司（欢乐互娱）的内部大数据分析平台，为运营、市场、产品等团队提供以下核心能力：

| 能力域 | 说明 |
|--------|------|
| 行为分析 | 事件分析、留存分析、漏斗分析、分布分析、间隔分析、SQL 分析 |
| 数据看板 | 多报表聚合看板，支持拖拽布局、移动端适配、外链嵌入 |
| 埋点管理 | Story（需求文档）管理、事件管理、数据核查 |
| 用户分析 | 用户搜索、用户详情、行为序列 |
| 标签管理 | 多类型标签创建（SQL/条件/指标/首末次/ID），标签组管理 |
| 数据资产 | 数据表管理、数据集（SQL/关联/条件）管理、属性管理 |
| 指标管理 | 指标定义、预览、关联看板/报表 |
| 预警管理 | 监控规则配置、预警列表、预警历史 |
| 管理功能 | 看板管理、报表管理、订阅管理、推送管理、任务管理、下载管理、枚举管理 |
| 财务模块 | 应收账款、流水对账、成本上传、历史数据归档等 |
| KoCRM | 社媒投放（达人/物料/账户管理）、营销模块（KOC 管理/一键联系） |
| 版本日历 | 版本信息标注日历 |

**主要用户**：公司内部各业务线运营、产品、数据人员（8种语言多国用户）

```typescript
class Request {
  // 创建 axios 实例
  // baseURL = VITE_APP_BASE_URL
  // withCredentials = true
  // transformResponse: 自定义大数值 JSON 解析（parseJsonWithBigNumberSupport）

  // 请求拦截器：设置 API Loading 状态

  // 响应拦截器（handleSuccessResponse）：
  // 1. 清除 Loading 状态
  // 2. responseType=blob → 直接返回
  // 3. code=20201 → 数据权限不足（setNoAuthModalInfo）
  // 4. code 在 [401, 10001-10004] → handleUnauthenticated()（退出登录）
  // 5. code !== 200 → errorMessage 弹出错误（可通过 forbiddenErrorMsg 禁止）
  // 6. 非 GET 成功 → message.success('操作成功')（可通过 forbiddenToast 禁止）

  // 请求头（自动注入）：
  // - Authorization: Bearer {token}
  // - PROJECT-ID: {currentProjectId}
  // - trace-id: {requestId}（UUID）
  // - config: JSON.stringify(headers.config ?? {})
  // - X-UA: {设备UA信息}
  // - href: {当前页面URL}
  // - language: {当前语言对应API value}
  // - 外链相关 headers（isExternalEmbedPage时）
}

## 17. 鉴权与权限体系

### 17.1 核心库：@joyu/auth ^0.2.20

```
Provider 层级：
UserInfoProvider（用户信息）
└── AuthedProjectsProvider（项目列表+当前项目）
    └── AuthProvider（权限树）
        └── useAllAuth()  // 获取所有权限
        └── useAuthLoading() // 权限加载状态
```

### 17.2 权限校验流程

```
1. UserInfoProvider 挂载
   → loginUser() API 获取用户信息
   → setUserInfo() 存入 Zustand

2. AuthedProjectsProvider 挂载
   → useAuthProject() 获取授权项目列表
   → 初始化 currentProject（第一个有权限的项目）
   → setAuthedProjects 存入 useSelectionStore

3. AuthProvider 挂载（以 currentProject 为上下文）
   → 加载权限树（allAuth）
   → 存入 localStorage（getAuthTreeKey()）

4. 路由渲染时
   → routeIsAccess(path) 检查权限树
   → 无权限 → NoAuthPage 或 Redirect
```

### 17.3 数据权限（code=20201）

```
API 返回 code=20201 时：
→ setNoAuthModalInfo({ authType: 'data', data_policy_keys: [...] })
→ ShowNoAuthModal 弹窗展示（Layout 底部渲染）
→ 用户可申请对应数据权限
```

### 17.4 Token 管理

```
存储位置：localStorage[`${KEY_PRE}TOKEN`]（JSON 序列化）
获取：getAuthToken() → src/utils/cookie.ts
注入：每次请求的 Authorization: Bearer {token}
失效处理：handleUnauthenticated() → 清除 userInfo → 跳转登录页
```

### 17.5 项目切换

```
ProjectSelector 组件（Layout Header）
→ 选择项目 → setProject(project) → Zustand global store
→ PROJECT-ID 头自动注入（每次请求）
→ 刷新各模块数据（refreshDeps: [currentProject?.code]）
```

## 1. 技术选型决策

### 1.1 主框架：Go + Gin

**选型理由**：

| 方案 | 优势 | 劣势 | 结论 |
|------|------|------|------|
| **Go + Gin** | 极高性能（原生并发/协程），编译型二进制，内存占用极低，天然适合 OLAP 分析服务 | 语法相对简洁但需要规范约束 | ✅ **首选** |
| NestJS (TS) | 前端同生态 | 性能低 5-10 倍，GC 抖动 | 前端熟悉但不适合高并发分析 |
| Python + FastAPI | 数据科学生态好 | GIL 限制并发 | AI/ML 子模块备选 |
| Java + Spring Boot | 成熟企业级 | 启动慢，内存重 | ❌ 不选 |

**Go 核心优势（针对本项目）**：
- **分析查询天然并发**：goroutine 轻量，单机可同时处理数千个 ClickHouse 查询
- **编译为单一二进制**：Docker 镜像仅 ~15MB（Alpine），启动 < 100ms
- **内存占用低**：同等负载下仅 Node.js 的 1/5，降低运维成本
- **静态类型**：编译期捕获错误，代码可靠性高
- **标准库强大**：内置 HTTP/JSON/加密/并发原语，减少外部依赖

### 1.2 技术栈汇总

### 2.1 服务拆分策略（单体 → 微服务渐进式）

**阶段一（当前）**：Go 单体应用，所有模块在同一进程，goroutine 并发
```
cmd/
└── server/           # 单体 Go HTTP Server（所有模块）
```

**阶段二（后期可拆分）**：
```
cmd/
├── server/           # 主 API 服务
├── analysis/         # 分析引擎（独立扩容，CPU 密集型）
├── worker/           # 异步任务 Worker（标签计算/导出）
└── notifier/         # 通知服务（推送/订阅/预警）
```

> **Go 的天然优势**：goroutine 极轻量（初始栈仅 2KB），无需微服务也能轻松处理数千并发分析请求

### 3.3 Dockerfile（多阶段构建）

```dockerfile
# ==== 构建阶段 ====
FROM golang:1.22-alpine AS builder

# 安装需要工具
RUN apk add --no-cache git ca-certificates tzdata

WORKDIR /build

# 先拷贝 go.mod/sum，利用 Docker 缓层
COPY go.mod go.sum ./
RUN go mod download

# 拷贝源码并构建
COPY . .

# 生成 Swagger 文档
RUN go install github.com/swaggo/swag/cmd/swag@latest && swag init -g cmd/server/main.go

# 静态编译，关闭调试信息，减小二进制体积
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build \
    -ldflags="-s -w -X main.Version=$(git describe --tags --always)" \
    -o joydata-server \
    ./cmd/server

# ==== 运行阶段 ====
# 使用 distroless 镜像，最小化攻击面
FROM gcr.io/distroless/static-debian12:nonroot

# 拷贝必要文件
COPY --from=builder /usr/share/zoneinfo /usr/share/zoneinfo
COPY --from=builder /etc/ssl/certs/ca-certificates.crt /etc/ssl/certs/
COPY --from=builder /build/joydata-server /app/joydata-server
COPY --from=builder /build/config /app/config  # 默认配置文件

WORKDIR /app
USER nonroot:nonroot
EXPOSE 3006

HEALTHCHECK --interval=30s --timeout=3s --start-period=5s \
  CMD ["/app/joydata-server", "health"]

ENTRYPOINT ["/app/joydata-server"]

# 鈥環预期：
# 最终镜像大小：~12MB（对比 NestJS ~300MB）
# 启动耗时：< 100ms（对比 NestJS ~3-5s）
```

CREATE TABLE users (
  id          BIGSERIAL PRIMARY KEY,

  email       VARCHAR(200) UNIQUE,
  password    VARCHAR(255),           -- bcrypt hash，SSO 登录可为空
  avatar      VARCHAR(500),

  lang        VARCHAR(20) DEFAULT 'zh_CN',
  login_method VARCHAR(20) DEFAULT 'uc', -- 'uc' | 'lark'
  lark_open_id VARCHAR(100),          -- 飞书 OpenID
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  updated_at  TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE projects (
  id          BIGSERIAL PRIMARY KEY,
  code        VARCHAR(100) UNIQUE NOT NULL, -- 项目标识符
  name        VARCHAR(200) NOT NULL,
  description TEXT,
  status      SMALLINT DEFAULT 1,
  config      JSONB DEFAULT '{}',     -- 项目配置（时区/货币等）
  created_by  BIGINT REFERENCES users(id),
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  updated_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 角色表
CREATE TABLE roles (
  id          BIGSERIAL PRIMARY KEY,
  project_id  BIGINT REFERENCES projects(id),
  name        VARCHAR(100) NOT NULL,
  description TEXT,
  permissions JSONB DEFAULT '[]',    -- 权限 key 数组
  is_system   BOOLEAN DEFAULT FALSE, -- 系统内置角色
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 用户项目角色关联
CREATE TABLE user_project_roles (
  id          BIGSERIAL PRIMARY KEY,

  project_id  BIGINT REFERENCES projects(id) ON DELETE CASCADE,
  role_id     BIGINT REFERENCES roles(id) ON DELETE CASCADE,
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (user_id, project_id, role_id)
);

-- 权限申请记录
CREATE TABLE auth_approvals (

  approver_id BIGINT REFERENCES users(id),
  approved_at TIMESTAMPTZ,
  created_at  TIMESTAMPTZ DEFAULT NOW()

### 4.2 ClickHouse — 分析表设计

```sql
-- 事件数据主表（核心分析表）
CREATE TABLE joydata_analytics.events (
  project_id      String,
  event_name      String,
  event_time      DateTime64(3, 'UTC'),   -- 毫秒精度
  user_id         String,
  device_id       String,
  session_id      String,
  -- 通用维度
  country         LowCardinality(String),
  region          LowCardinality(String),
  language        LowCardinality(String),
  os              LowCardinality(String),
  app_version     LowCardinality(String),
  -- 事件属性（动态）
  properties      Map(String, String),    -- 字符串属性
  properties_num  Map(String, Float64),   -- 数值属性
  -- 分区键
  date_key        Date MATERIALIZED toDate(event_time)
)
ENGINE = MergeTree()
PARTITION BY (project_id, toYYYYMM(date_key))
ORDER BY (project_id, event_name, event_time, user_id)
SETTINGS index_granularity = 8192;

-- 用户属性快照表
CREATE TABLE joydata_analytics.user_profiles (
  project_id      String,
  user_id         String,
  entity_type     LowCardinality(String),
  first_seen      DateTime64(3, 'UTC'),
  last_seen       DateTime64(3, 'UTC'),
  -- 属性（动态）
  attrs           Map(String, String),
  attrs_num       Map(String, Float64),
  -- 更新时间
  updated_at      DateTime64(3, 'UTC'),
  date_key        Date MATERIALIZED toDate(updated_at)
)
ENGINE = ReplacingMergeTree(updated_at)
PARTITION BY (project_id, toYYYYMM(date_key))
ORDER BY (project_id, entity_type, user_id);

-- 物化视图：日活/月活统计
CREATE MATERIALIZED VIEW joydata_analytics.mv_dau
ENGINE = SummingMergeTree()
PARTITION BY (project_id, toYYYYMM(date_key))
ORDER BY (project_id, date_key, event_name)
AS SELECT
  project_id,
  toDate(event_time) AS date_key,
  event_name,
  uniqState(user_id) AS uv_state,
  count() AS pv,
  sum(properties_num['duration'] ) AS total_duration
FROM joydata_analytics.events
GROUP BY project_id, date_key, event_name;

-- SQL 分析历史
CREATE TABLE joydata_analytics.sql_query_history (
  id              UUID DEFAULT generateUUIDv4(),
  project_id      String,
  user_id         String,
  sql_content     String,
  status          UInt8,              -- 1:运行中 2:成功 3:失败
  duration_ms     UInt32,
  row_count       UInt64,
  error_msg       String,
  created_at      DateTime64(3, 'UTC')
)
ENGINE = MergeTree()
ORDER BY (project_id, created_at)
TTL created_at + INTERVAL 90 DAY;
```

### 4.3 Redis Key 设计

```
# Session
session:{user_id}:{project_id}          → JWT + 用户信息（TTL: 7d）
auth_tree:{project_id}:{user_id}        → 权限树 JSON（TTL: 1h）

# 查询缓存
analysis_cache:{project_id}:{hash}      → 查询结果（TTL: 5min）
dashboard_cache:{dashboard_id}          → 看板快照（TTL: cron时间）

# 任务取消
query_cancel:{trace_id}                 → 1（TTL: 1h）

# 并发控制
analysis_lock:{project_id}:{user_id}    → 1（TTL: 30s，防止重复请求）

# 站内信未读计数
notice_unread:{user_id}                 → count（TTL: 无）

# 限流
rate_limit:{user_id}:{api}              → count（TTL: 1min）

# 任务队列（asynq - 基于 Redis）
asynq:{queue_name}                   → sorted set
asynq:{queue_name}:active            → set
asynq:{queue_name}:scheduled         → sorted set

    "joydata-backend/config"
    "joydata-backend/internal/app"
    "joydata-backend/pkg/logger"
)

func main() {
    // 加载配置
    cfg := config.Load()

    // 初始化日志
    log := logger.New(cfg.LogLevel)
    defer log.Sync()

    // 初始化应用（依赖注入）
    application, cleanup, err := app.New(cfg, log)
    if err != nil {
        log.Fatal("应用初始化失败", zap.Error(err))
    }
    defer cleanup()

    // 启动 HTTP 服务器
    srv := &http.Server{
        Addr:         ":" + cfg.Port,
        Handler:      application.Router,
        ReadTimeout:  30 * time.Second,
        WriteTimeout: 60 * time.Second,
    }

    // 优雅退出
    go func() {
        if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
            log.Fatal("服务器启动失败", zap.Error(err))
        }
    }()

    log.Info("服务器已启动", zap.String("addr", srv.Addr))

    quit := make(chan os.Signal, 1)
    signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
    <-quit

    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()
    srv.Shutdown(ctx)
}

### 6.3 全局错误捕获（Recovery 中间件）

```go
// internal/middleware/recovery.go
package middleware

import (
    "net/http"
    "github.com/gin-gonic/gin"
    "go.uber.org/zap"
    "joydata-backend/internal/types"
)

func Recovery(log *zap.Logger) gin.HandlerFunc {
    return func(c *gin.Context) {
        defer func() {
            if err := recover(); err != nil {
                log.Error("内部错误", zap.Any("error", err),
                    zap.String("path", c.Request.URL.Path))
                types.Error(c, types.CodeInternalError, "服务器内部错误")
                c.Abort()
            }
        }()
        c.Next()
    }
}

// 标准错误处理示例（在 Handler 中使用）
func HandleErr(c *gin.Context, err error) bool {
    if err == nil {
        return false
    }
    switch e := err.(type) {
    case *types.AppError:
        types.Error(c, e.Code, e.Message)
    default:
        types.Error(c, types.CodeInternalError, err.Error())
    }
    return true
}

// internal/middleware/ratelimit.go
package middleware

import (
    "fmt"
    "time"
    "github.com/gin-gonic/gin"
    "github.com/redis/go-redis/v9"
    "joydata-backend/internal/types"
)

// 分析查询限流：每用户每分钟最多 20 次
func AnalysisRateLimit(rdb *redis.Client) gin.HandlerFunc {
    return func(c *gin.Context) {
        userID, _ := c.Get("user_id")
        key := fmt.Sprintf("rate_limit:%v:query", userID)

        count, _ := rdb.Incr(c.Request.Context(), key).Result()
        if count == 1 {
            rdb.Expire(c.Request.Context(), key, time.Minute)
        }
        if count > 20 {
            types.Error(c, 429, "请求过于频繁，请稍后再试")
            c.Abort()
            return
        }
        c.Next()
    }
}

  project_id: string;

    alias?: string;
  }>;
  group_by?: Array<{
    property: string;
    datatable?: string;
  }>;
  global_filters?: FilterCondition[];
  user_group?: {

  };

## 8. 数据分析引擎设计

### 8.1 QueryBuilder 架构

```typescript
// 基础 QueryBuilder 接口
abstract class BaseQueryBuilder {
  abstract build(params: AnalysisQueryRequest): string;

  protected buildDateFilter(dateRange: DateRange): string {
    return `toDate(event_time) BETWEEN '${dateRange.start}' AND '${dateRange.end}'`;
  }

  protected buildPropertyFilter(filters: FilterCondition[]): string {
    return filters.map(f => this.buildCondition(f)).join(' AND ');
  }

  protected buildCondition(condition: FilterCondition): string {
    const { property, operator, value } = condition;
    switch (operator) {
      case 'eq':   return `${property} = '${value}'`;
      case 'ne':   return `${property} != '${value}'`;
      case 'gt':   return `${property} > ${value}`;
      case 'gte':  return `${property} >= ${value}`;
      case 'lt':   return `${property} < ${value}`;
      case 'lte':  return `${property} <= ${value}`;
      case 'in':   return `${property} IN (${value.map(v=>`'${v}'`).join(',')})`;
      case 'like': return `${property} LIKE '%${value}%'`;
      case 'null': return `isNull(${property})`;
      // ...更多操作符
    }
  }
}
```

### 8.2 各分析类型 SQL 生成

#### 事件分析
```sql
-- 事件分析：每日 UV/PV
SELECT
  toDate(event_time) AS date,
  {group_by_columns},
  uniq(user_id) AS uv,
  count() AS pv,
  {metric_calculations}
FROM joydata_analytics.events
WHERE
  project_id = '{project_id}'
  AND event_name = '{event_name}'
  AND toDate(event_time) BETWEEN '{start}' AND '{end}'
  AND {global_filters}
  AND {user_group_filter}
GROUP BY date, {group_by_columns}
ORDER BY date ASC
```

#### 留存分析
```sql
-- 留存分析（使用 windowFunnel 或 自关联）
WITH
  first_event AS (
    SELECT user_id, min(toDate(event_time)) AS first_date
    FROM joydata_analytics.events
    WHERE project_id = '{project_id}'
      AND event_name = '{initial_event}'
      AND toDate(event_time) BETWEEN '{start}' AND '{end}'
    GROUP BY user_id
  ),
  retention_data AS (
    SELECT
      fe.first_date,
      dateDiff('day', fe.first_date, toDate(e.event_time)) AS day_offset,
      count(DISTINCT e.user_id) AS retained_users
    FROM first_event fe
    JOIN joydata_analytics.events e ON fe.user_id = e.user_id
    WHERE e.project_id = '{project_id}'
      AND e.event_name = '{return_event}'
      AND dateDiff('day', fe.first_date, toDate(e.event_time)) BETWEEN 0 AND {window}
    GROUP BY fe.first_date, day_offset
  )
SELECT
  first_date,
  groupArray(day_offset) AS days,
  groupArray(retained_users) AS users
FROM retention_data
GROUP BY first_date
ORDER BY first_date
```

### 8.3 查询取消机制

```typescript
// Redis 存储取消信号
async cancelQuery(traceId: string) {
  await this.redis.setEx(`query_cancel:${traceId}`, 3600, '1');
}

// ClickHouse 客户端带检查点
async executeWithCancellation(sql: string, traceId: string) {
  const queryId = `joydata_${traceId}`;
  try {
    // ClickHouse 原生支持 query_id，可通过 KILL QUERY 取消
    const result = await this.clickhouse.query({
      query: sql,
      query_id: queryId,
    });
    return result;
  } catch (err) {
    if (await this.redis.get(`query_cancel:${traceId}`)) {
      // 主动取消
      await this.clickhouse.query({ query: `KILL QUERY WHERE query_id='${queryId}'` });
      throw new CancelledException();
    }
    throw err;
  }
}
```

@Injectable()
export class SchedulerService {
  // 每分钟检查预警规则
  @Cron('* * * * *')
  async checkWarnings() {
    const activeWarnings = await this.warningService.getActiveWarnings();
    for (const warning of activeWarnings) {
      await this.warningQueue.add('check', warning, { priority: PRIORITIES.SCHEDULED });
    }
  }

  // 每天凌晨2点刷新标签
  @Cron('0 2 * * *')
  async refreshTags() {
    const activeTags = await this.tagService.getActiveAutoRefreshTags();
    for (const tag of activeTags) {
      await this.tagQueue.add('compute', tag, { priority: PRIORITIES.BACKGROUND });
    }
  }

  // 每5分钟清理过期下载文件
  @Cron('*/5 * * * *')
  async cleanExpiredDownloads() {
    await this.downloadService.cleanExpired();
  }
